# YouTube 채널 운영 가이드 (LMS 연동용)

LMS(`lms-youtube-testbed`)는 **YouTube 일부 공개(Unlisted)** 영상을 임베드하고, **진도·완료는 Supabase**에서 관리합니다.  
이 문서는 **YouTube 계정·채널·업로드·LMS 등록** 절차만 다룹니다.

---

## 1. 계정·채널 만들기

### 1-1. Google 계정

- 회사용 **Google Workspace** 메일이 있으면 그 계정 사용을 권장합니다.
- 개인 Gmail만 있으면, 나중에 관리자 이관이 어려울 수 있어 **교육 담당 공용 계정** 생성을 권장합니다.

### 1-2. YouTube 채널 생성

1. https://www.youtube.com 접속 후 로그인
2. 프로필 아이콘 → **채널 만들기** (또는 YouTube Studio 최초 진입 시 안내)
3. **브랜드 계정** 권장  
   - 채널명 예: `EVKMC 사내교육` / `LMS 교육영상`  
   - 여러 관리자를 **브랜드 계정 관리자**로 초대 가능 (개인 Gmail에 묶이지 않음)

### 1-3. 채널 기본 설정 (YouTube Studio)

| 메뉴 | 권장 |
|------|------|
| **설정 → 채널 → 기본 정보** | 채널 설명에 «사내 수강 전용, 외부 공유 금지» 등 명시 |
| **설정 → 채널 → 고급 설정** | «아동용» 해당 없음으로 정확히 설정 (제한 방지) |
| **설정 → 업로드 기본값** | 아래 «업로드 기본값» 참고 |

## 2. 보안·공개 범위 (LMS에 맞는 설정)

### 영상 공개 상태

| 설정 | LMS 사용 |
|------|----------|
| **공개** | ✗ 검색·추천에 노출 |
| **일부 공개 (Unlisted)** | **◎ 기본값** — 링크·ID 아는 사람만 시청 |
| **비공개** | △ LMS 임베드·API 동작이 깨질 수 있어 **비추천** |

> 일부 공개도 **ID/URL을 알면 외부 시청·다운로드는 가능**합니다.  
> LMS에서는 **수강 등록 게이트 + (예정) 워터마크**로 보완합니다.

### 업로드 기본값 (Studio → 설정 → 업로드 기본값)

- **공개 상태:** 일부 공개  
- **카테고리:** 교육  
- **시청자층:** «아니요, 아동용이 아닙니다» (회사 교육 콘텐츠)  
- **댓글:** 끔 (선택)  
- **Shorts에 사용:** 필요 없으면 끔  

### 임베드 (선택)

- **Studio → 콘텐츠 → 영상 → 편집 → 세부정보 → «다른 웹사이트에서 재생 허용»**  
- 가능하면 **도메인 제한**에 LMS 도메인만 추가  
  - 예: `lms-youtube-testbed.vercel.app`  
  - 커스텀 도메인 사용 시 해당 도메인도 추가  

※ 도메인 제한을 켜도 **youtube.com에서 직접 URL로 보는 것**까지 막히지는 않는 경우가 많습니다.

## 3. 영상 업로드 워크플로

### 3-1. 업로드 전 (MP4)

| 항목 | 권장 |
|------|------|
| 형식 | MP4, H.264 + AAC |
| 해상도 | 1080p 또는 **720p** (용량·로딩 균형) |
| 용량 | 100MB 미만 목표 (이미 다운사이즈한 파일 그대로 사용 가능) |
| 제목 규칙 | `[코스명] 1강. 제목` — Studio 목록과 LMS 레슨명 통일 |

### 3-2. 업로드

1. **YouTube Studio** → **만들기** → **동영상 업로드**
2. 파일 선택 후 제목·설명 입력
3. **공개 상태: 일부 공개** 확인
4. **재생목록**에 코스별 재생목록 추가 (Studio 관리용, LMS와 무관해도 됨)
5. 업로드·처리 완료까지 대기 (HD 처리에 수 분~수십 분)

### 3-3. YouTube ID 확인

영상 URL 예:

```text
https://www.youtube.com/watch?v=dQw4w9WgXcQ
                              ^^^^^^^^^^^
                              이 11자리가 youtube_id
```

Shorts/공유 URL이 `youtu.be/XXXXXXXXXXX` 형태여도 **슬래시 뒤 11자리**가 ID입니다.

## 4. LMS에 레슨 등록

### 방법 A — Supabase Table Editor

`lessons` 테이블에 행 추가:

| 컬럼 | 값 |
|------|-----|
| `course_id` | 해당 강의 UUID |
| `title` | 레슨 제목 |
| `lesson_type` | `video` |
| `youtube_id` | 위에서 복사한 11자리 |
| `duration_seconds` | 영상 길이(초) — 진도 % 계산용 |
| `sort_order` | 1, 2, 3… |
| `is_free` | 필요 시 true |

### 방법 B — 샘플 API (개발·데모)

관리자 `/admin` → 샘플 시드 (실제 영상 ID로 `seed-sample` 수정 후 실행)

### 방법 C — SQL 예시

```sql
INSERT INTO lessons (course_id, title, lesson_type, youtube_id, duration_seconds, sort_order, is_free)
VALUES (
  '11111111-1111-1111-1111-111111111111',
  '1강. 전기차 기초',
  'video',
  '여기에_YouTube_ID',
  540,
  1,
  true
);
```

## 5. 채널·권한 관리 (2인 이상 운영)

### 브랜드 계정 관리자 추가

1. https://myaccount.google.com → **사용자 및 공유** (또는 브랜드 계정 설정)
2. **관리자 초대** — 업로드·Studio 접근만 필요한 담당자
3. **소유자**는 1~2명만 유지

### 역할 분리 (권장)

| 역할 | YouTube | LMS |
|------|---------|-----|
| 콘텐츠 제작 | 업로드·편집·일부 공개 설정 | — |
| 교육 운영 | 재생목록·메타 정리 | 수강 등록·진도 확인 (`/admin`) |
| 시스템 | — | Supabase·Vercel env |

**LMS 관리자**는 `NEXT_PUBLIC_ADMIN_EMAIL`과 일치하는 계정으로 `/admin` 접속 (YouTube 계정과 동일할 필요 없음).

## 6. 코스 7편 운영 체크리스트

- [ ] 채널·업로드 기본값: **일부 공개**
- [ ] 영상 7개 업로드, 제목·순서 통일
- [ ] 각 영상 **youtube_id** + **duration_seconds** 스프레드시트에 기록
- [ ] Supabase `lessons`에 `sort_order` 순서대로 입력
- [ ] LMS에서 **수강 신청 → 레슨 재생 → 진도 저장** 테스트
- [ ] (선택) 재생목록을 코스별로 Studio에만 정리
- [ ] (예정) 레슨 플레이어 **동적 워터마크** 적용

## 7. 자주 하는 실수

| 증상 | 원인 | 해결 |
|------|------|------|
| LMS에서 «동영상을 재생할 수 없음» | 비공개·연령 제한·지역 제한 | Studio에서 일부 공개·시청 제한 확인 |
| 진도가 0%만 | `duration_seconds` 잘못됨 | Studio에서 실제 길이(초) 재입력 |
| 임베드만 안 됨 | 도메인 제한 | LMS URL을 허용 목록에 추가 |
| ID가 안 맞음 | URL 전체를 넣음 | **11자리 ID만** `youtube_id`에 저장 |

## 8. YouTube vs LMS 역할 (다시 정리)

```text
YouTube  → 파일 호스팅·스트리밍·일부 공개 링크
LMS      → 로그인·수강·진도 90% 완료·관리자 리포트·(워터마크)
```

채널 구독자 수·댓글 커뮤니티는 **필수 아님**.  
**재생목록·Studio 정리**는 운영 편의용이고, 학습 관리의 기준은 항상 **LMS + Supabase**입니다.
